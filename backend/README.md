# DhanaChakra Backend

Backend API for the CashFlow product developed for
Kalpvruksh 2.0 Mini Hackathon — Problem P05.

## Tech Stack

- Node.js
- Express.js
- PostgreSQL
- Clerk
- Gemini

## Development Approach

The backend is developed phase by phase using
spec-driven development.

Each phase is completed and tested through Postman
before moving to the next phase.
